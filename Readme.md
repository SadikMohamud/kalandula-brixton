# Kalandula Bar & Grill (v2)

Website for Kalandula Bar & Grill, an Angolan Portuguese restaurant at 5 Brixton Station Road, London SW9 8PA. Live at kalandula.co.uk.

## What's in v2
- Hero: the Kalandula Falls video plays inside the wordmark, then opens to full screen as you scroll
- Story section with a word by word reading reveal, parallax photography and live counters
- Menu with category tabs, built from `assets/js/menu-data.js`
- Cascade gallery where the food photography flows down the page like water
- Ink reveal navigation, magnetic buttons, Lenis smooth scrolling
- Tableo booking links throughout, restaurant schema for Google
- Respects reduced motion settings

## Editing
- **Menu and prices:** edit `assets/js/menu-data.js`
- **Photos:** `assets/img/` (WebP, max 1600px)
- **Styles:** `assets/css/style.css`

Static site, no build step. Hosted on GitHub Pages (see `CNAME`).
